# 群岛：RSI 研究观察台概念 v1

2026-10-26，使用内置图像生成工具制作。dashboard.png 为视觉概念，prompt.txt 为完整生成提示词。

参考 Athanor 的研究记录与模型/方法复用，以及 Oil UI 的焦点、层级和减法原则：

- https://arxiv.org/abs/2610.21055v1
- https://github.com/oil-oil/oil-ui

核心视觉：米白、墨黑、灰绿；细等高线分组研究岛，节点表示模型版本。等高线不表示测得的能力距离。

核心交互设想：点岛看研究历史，点桥看迁移假设/代码/训练/评测证据，拖时间轴回看当时掌握的信息。

选中桥使用 R03→R02 与混合解码 rollout 作为设计示例；同时显示已复用与待消融，避免把共享事件当成因果收益证据。底部将模型表现与研究机制进步分开，没有 RSI 综合指数。

图中布局、数字、状态与曲线均为示意，没有接入实际服务。生成图中的细字与图标仍需在实现时重新排版和校对，不能直接作为像素级功能规范。当前未实现看板代码。
