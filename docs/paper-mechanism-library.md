# 论文机制岛（规划，尚未实现）

用户已确认：按可独立检验机制分岛；一篇论文可以拆多个岛，多篇同机制可经显式归并进入同岛。主题/关键词相近不足以归并。来源为运行时政策允许的已录用公开论文，原文、AI解读、迁移假设与本地验证分开记录。

完整范围、接口和验收见 [review](../openspec/changes/paper-mechanism-island-library/review.md) 与 [design](../openspec/changes/paper-mechanism-island-library/design.md)。未来由独立 curator 身份整理，四个研究会话只读灵感；不在控制服务隐藏调用模型，也不授权训练或改变 benchmark 方向。

**默认没有桥。** 共现/相似度/同论文都不构成桥。例外要有论文自身对照或消融、固定正文引用、条件和raw结果，经独立受权审查后仅作为 paper_reported 边；不等于本地复现或安全场景迁移已有效。录用是来源筛选条件，方法结论始终保留设置与局限。

首个计划来源为 OpenReview v2 公开已录用记录，其他出版源与API v1明确待适配。本文不定义具体顶会名单/年份，不代表任何真实论文已摄入。新62项契约当前RED，产品命令不可调用；CI/CD新增门禁会阻断发布，不绕过原研究层RED。
